# dashboard_porsche
Dashboard feito para o curso Aceleração Santander
O dashboard foi feito no Claude pois a versão gratuita do GPT não conseguiu analisar todos os dados.
Foi utilizada a planilha sanitizada fornecida pela DIO, tratada removendo-se as colunas não sanitizadas.
As perguntas de negócio foram:
Qual modelo de Porsche é mais vendido por Estado?
Quais anos de modelos de Porsche são mais populares?
Quais vendedores estão conseguindo mais vendas?
